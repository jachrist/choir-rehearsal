# choir-rehearsal

Dette repoet inneholdt opprinnelig et utforskende prosjekt for å bygge en egen
OMR-pipeline (PDF → MusicXML med sangtekst) for å produsere øvingsfiler til et kor.

Etter vurdering ble konklusjonen at det ikke er verdt å bygge et eget verktøy –
eksisterende verktøy (MuseScore + Cantamus) løser oppgaven godt nok. Koden fra
den tidlige utforskingen er derfor fjernet.

Se [`omr-kor-prosjekt-brief.md`](omr-kor-prosjekt-brief.md) for dokumentasjon på
hva som ble vurdert.
